🔗 https://commute-expense-visualizer-wp6d7ws6s2rrn8espqsbmd.streamlit.app/

---

## 🎯 Project Overview
Instead of relying on static pre-made datasets, this project focuses on **primary data collection** from real-world daily transit (such as MSRTC bus schedules vs. two-wheeler commutes) and day-to-day student budgeting.

### Key Analytical Questions Answered:
- **Transit Efficiency:** Which departure slots experience the highest traffic delays?
- **Cost Optimization:** How do daily fuel/auto expenses compare against a fixed monthly student bus pass?
- **Budget Distribution:** What proportion of monthly student spending goes toward transit, canteen/food, and academic supplies?

---

## ✨ Features
- **➕ Real-Time Data Logging:** Sidebar form to quickly log daily travel mode, scheduled vs. actual duration, delay reasons, and itemized expenses (₹).
- **📊 Automated KPI Metrics:** Instant calculation of total days logged, average one-way commute duration, average daily delay, and total variable spend.
- **⏱️ Interactive Delay Visualization:** Stacked bar charts comparing scheduled travel time against actual transit delays using Plotly.
- **💸 Expense Breakdown:** Interactive donut chart categorizing spending across Transit, Food/Canteen, and Academic/Misc.
- **📋 Raw Dataset Inspector:** Sortable and filterable in-app data table.
